# Quiz maker 2.0 tutorial

A narrated walkthrough of the installed plugin in Obsidian. Screens use public sample content and a demo provider; they do not show a live provider or an API key.

## Start with a note

Quiz maker turns notes into practice. This walkthrough uses public sample notes and a demo provider. Open a note, then use the command palette to choose Quick quiz. To write questions yourself, choose New quiz.

## Choose your study pack

The current note is selected for you. Choose a study pack and a question mix. Keep the defaults for a quick start, or open the optional controls when you need them.

## Connect and choose a model

In settings, choose your provider and endpoint. Add an API key for a hosted provider. Find models checks the connection and loads the available list. Search, then select a model. Manual model IDs remain available.

## Generate and review

Generate your quiz. Only the selected notes go to the configured provider. Review generated questions and reference answers against your source before studying.

## Practice at your pace

Answer a question, check your response, and move on. Choose an exam when you want a timer and answers hidden until submission. Your progress stays in the vault.

## Keep practice beside your notes

The mini view shares the same session beside your notes. Use the full view when you want more space. Quiz appearance can follow your Obsidian theme.

## Edit, save and export

Edit questions and undo changes when needed. Export JSON, Anki cards, or a PDF. Saved packs and preferences stay in place across updates. The written guide is linked in the repository.
