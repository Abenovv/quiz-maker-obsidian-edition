## Import and export dependencies

These libraries run locally. Their inclusion does not send quiz content to another service. The build retains their license text in `main.js`.

| Library | Version | License | Purpose |
| --- | --- | --- | --- |

| sql.js | 1.15.2 | MIT | In-memory SQLite package conversion. |
